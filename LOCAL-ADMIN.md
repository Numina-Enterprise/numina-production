# Local admin console (local network only)

The private Numina handlers (MCP and MCP discovery, `/api/control`, treasury, financial, NUSD,
ops, app, reviewer, `/v1`–`/v5` runtime routes) and the private downloads are **not** served on
numinalabs.xyz or www: the public Worker answers them with a 403 "This section is private"
notice. They are served only by the local server in `src/local/`, which is never part of the
production build (`scripts/build.mjs` does not include it; `tests/local-admin.test.mjs` checks).

```bash
npm ci && npm run build                      # dist/private-downloads holds the unpublished files
export NUMINA_LOCAL_ADMIN_TOKEN='<16+ random characters>'   # PowerShell: $env:NUMINA_LOCAL_ADMIN_TOKEN='...'
npm run local-admin                          # http://127.0.0.1:8790/admin (loopback only)
npm run local-admin -- --host 192.168.1.20 --allow-lan     # explicit LAN opt-in, one specific address
```

- `/admin`: inspect the private MCP connection config; view and edit the local treasury API
  route config (`local-data/treasury-route-config.json`; config only, no signing, no keys, no
  provider or financial calls; secret-looking fields are rejected); browse, add and remove files
  in `local-data/private-downloads/` (build files in `dist/private-downloads/downloads` are
  read-only and regenerated by `npm run build`).
- `/admin/treasury/*`: mount point for the separately built `local/treasury/routes.mjs` module
  (returns 404 NOT_INSTALLED until that module is merged).
- Write actions need `Authorization: Bearer $NUMINA_LOCAL_ADMIN_TOKEN`; with no token set, writes
  are disabled. The token is read from the environment only and is never written to disk.
- `local-data/` is git-ignored. Operations, key custody and recovery: `docs/LOCAL-ADMIN-RUNBOOK.md`.
