# Numina Authority Physics v0.2

## Constitutional kernel
Numina evaluates proposed economic state transitions against a conserved, dependency-bound authority state. The only decision values are `ALLOW`, `DENY`, and `ESCALATE`.

## Core invariants
C1 Authority Non-Creation; C2 Attenuation; C3 Exclusive Occupancy; C4 Commit Uniqueness; C5 Reality Preservation; C6 No Optimistic Release; C7 Finality Non-Bootstrapping; C8 Dependency Closure; C9 Historical Immutability; C10 Administrative Non-Sovereignty; C11 Atomic Transition; C12 Projection Equivalence; C13 Deterministic Projection; C14 Recovery Reachability.

## Distributed law
Shared authority is either serialized or partitioned before independent use. Eventual consistency must not mint authority from a shared free pool. Fencing epochs kill stale shard authority after recall/reissue.

## Failure law
For any failure transition, risk-adding reachable authority must not increase merely because information became less certain. Unknown external effect remains occupied until proof narrows possibility.

## Credential law
Authentication proves identity; a Numina Economic Authorization Credential proves bounded economic power for one exact operation under one dependency closure and Constitution identity. Endpoint recognition can only narrow issued authority.
