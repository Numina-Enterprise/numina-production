# Numina Authority Physics v0.6 — Federated Global Fabric

v0.6 extends the reference model from a distributed proof plane into independently sovereign authority domains.

## Laws
1. Recognition may only narrow issued authority.
2. Recognition is non-transitive by default.
3. Multi-principal actions require explicit threshold semantics and shared consequence bounds.
4. Coalition composition cannot manufacture emergent authority; joint action requires an explicit CompositionRight/CoalitionPolicy.
5. Route optimization may optimize cost only inside legitimate recognition constraints.
6. Systemic MREC is conservative: correlated or unknown exposures are not discounted without proof.
7. Shared dependencies are first-class concentration risks.
8. Sovereign domains may retain independent rights roots, policies, jurisdictions, and implementations while sharing Numina conservation semantics.

## New reference primitives
- SovereignDomain
- RecognitionBridge
- MultiPrincipalPolicy
- CoalitionPolicy
- AuthorityRouteEdge / AuthorityRoute
- DomainExposure / systemic MREC
- Composition emergence analysis

The global fabric remains compatible with C1-C14: federation changes recognition and routing, not the conservation source of authority.
