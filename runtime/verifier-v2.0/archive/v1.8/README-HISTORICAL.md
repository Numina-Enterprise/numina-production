# Archive: v1.8 — historical record only

This folder is the v1.8 historical record. It is **not** current verification
for V2.0.

- `FROZEN-CORE-v1.8.sha256` — original v1.8 hash list, verbatim.
- `MANIFEST.sha256`, `MANIFEST.production.sha256`, `SOURCE-ARCHIVE.sha256` —
  original v1.8-era manifests, verbatim.
- `README-v1.8.md` — original v1.8 verifier README, verbatim.

V1.8 was unfrozen by owner direction, merged into V2.0, and then V2.0 was
frozen again under its own manifest. V1.8's frozen verification does not
apply to V2.0. Do not use this folder to verify V2.0.
