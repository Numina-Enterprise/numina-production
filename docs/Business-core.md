# Numina business core

Numina is blockchain and authority infrastructure for the agent economy, unifying agents, software, code, assets, liquidity, verification and evidence. Time is expressed through expiry, event order and timestamps; space through network, jurisdiction, system and resource scope. This business architecture informs every website, app, integration and plugin release.

The production core remains one root, one journal and one NUSD projection. External funding, token deployment, provider settlement and distribution approvals retain their actual evidence status. Owner-authorized funding-plan receipts prove that a plan was recorded, not that funds were deposited.

Core definition: `/business-core.json`. Live releases: `/v2/release/manifest`.
