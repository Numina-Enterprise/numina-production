# Numina security

Numina maintains one security and financial control model across its connected system. See [the canonical security document](docs/Numina-Security.md), published at https://numinalabs.xyz/security.

Report security issues to skott34@numinalabs.xyz with subject **Numina security report**. Provide a minimal reproduction and arrange a secure channel before sharing sensitive material. Private credentials, financial records and other users' information do not belong in public issues.

Implemented controls, dated verification results and unverified operating requirements have separate evidence states in that document. Publication is not an independent security certification or financial authorization.
