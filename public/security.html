IMPLEMENTED CONTROLS

Access, input validation and record integrity.

Server-side access checks restrict customer records and owner operations. Requests use bounded inputs, revision checks and replay controls. Private API and payment responses stay outside the app's offline cache.

Payment reconciliation checks provider-confirmed facts. The Numina-native treasury retains one canonical journal; provider observations keep their original source, currency and verification scope.
