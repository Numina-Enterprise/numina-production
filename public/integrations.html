Production MCP

Hosted discovery exposes architecture, capabilities and the current journal head. The downloadable kit also supplies six read-only discovery tools over standard input and output.

Integration kit 4.0.0 includes release-manifest and runtime-build discovery, existing service discovery and local MCP. Runtime-build details are reported by the server; the client does not independently verify signatures or establish host deployment or financial execution. Live provider installation and acceptance have not been verified. Each host requires its own installation and permissions. The kit includes Numina’s GeForce RTX target-group configuration and Windows/WSL container bootstrap. GPU inference, per-device model compatibility and public-service entitlement require verified deployment inputs.

Public discovery is available. NUSD quotes, payment requests and settlement are disabled. The integration package never mints tokens, transfers funds, or trusts a model-supplied payment flag.
