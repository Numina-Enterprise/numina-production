02 / INTEGRATION LIFECYCLE

Move from interface fit to acceptance.

Discover
Confirm the documented API or tool, schema and version. Public discovery does not grant execution permission.
Evaluate
Use synthetic or approved data. Test authentication, idempotency, errors, retries and reconciliation for the intended action.
Qualify
Agree permitted data, credentials, provider limits, monitoring, incident ownership and acceptance criteria.
Operate
Review the deployed version and the relevant provider receipts. Track changes against the agreed operating scope.

03 / ACCESS & SUPPORT

Define production requirements explicitly.

Availability is specific to the interface, host and account. A downloadable adapter does not establish a completed provider installation. Authentication, rate limits, hosting, data location, support and any service-level commitments are reviewed during scoping.

Planning a production integration?
