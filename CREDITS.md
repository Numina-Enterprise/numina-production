# Credits

## Paul Miller — noble cryptography

Numina's release signing and verification rely on the **noble** cryptographic libraries, created and maintained by [Paul Miller](https://paulmillr.com/noble/):

- `@noble/post-quantum`: FN-DSA-1024 release signatures
- `@noble/curves`: Ed25519 release signatures
- `@noble/hashes`
- `@noble/ciphers`

- Project page: https://paulmillr.com/noble/
- Funding page: https://paulmillr.com/funding/ (GitHub Sponsors: https://github.com/sponsors/paulmillr)
