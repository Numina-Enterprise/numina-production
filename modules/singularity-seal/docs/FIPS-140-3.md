# FIPS 140-3 status

Author: Samuel J. Kott
Operator: SK Consulting LLC dba Numina Labs
Copyright (c) 2026 Samuel J. Kott and SK Consulting LLC dba Numina Labs

There is no FIPS 140-3 validation for this module.

FIPS 140-3 validation is a certificate from the Cryptographic Module Validation Program (CMVP). A lab accredited for that program tests a defined cryptographic module and CMVP publishes the certificate. Passing known-answer tests in this repository does not create that certificate, and no source change here can. The ACVP files under `vectors/` check that ML-DSA-65 behaves like the FIPS 204 samples. They are not a CMVP certificate and they do not name this product.

## What a validation path would look like

1. Draw a module boundary. CMVP certifies that boundary, including the software or hardware that performs the cryptographic operations, its operating environment, and the ports and roles. `@numina/singularity-seal` as shipped calls `@noble/post-quantum` 0.7.1 for ML-DSA-65 and Node.js `crypto` for Ed25519. Those dependencies are outside a boundary this repository has submitted.
2. Choose whether to build on a module that already has a CMVP certificate, or to submit a new module. A new module needs an accredited laboratory, an implementation inside the stated boundary, and the security policy the lab files with CMVP.
3. Run the algorithm tests the program requires for each approved algorithm in the boundary (CAVP, using ACVP). ML-DSA is FIPS 204. Ed25519 is not a post-quantum algorithm. A composite construction is an application of those primitives. The certificate, if any, would list the algorithms the lab actually tested, not this package name by itself.
4. Wait for CMVP review. The result is a certificate number on the public CMVP module list. Until that number exists, this module must be described as not FIPS 140-3 validated.

This repository has not engaged a CMVP laboratory, has not filed a security policy, and has not received a certificate number.
